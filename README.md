# Определение ориентации текста

Решение задачи классификации текстовых боксов: для каждого изображения модель оценивает вероятность того, что текст повёрнут на 180°.

## Файлы

- [`Text_Orientation.ipynb`](Text_Orientation.ipynb) — разбор решения и создание `submission.csv`.
- [`text_orientation_finetuned.onnx`](text_orientation_finetuned.onnx) — веса дообученной модели.

## Запуск

1. Положите ноутбук и ONNX-файл в одну папку. Рядом разместите тестовые PNG в `test/test/images/` или `test/images/`, а `sample_submission.csv` — в `test/`.
2. Установите зависимости: `pip install numpy pillow onnxruntime jupyter`.
3. Откройте ноутбук и выполните все ячейки. Результат появится в `submission.csv` рядом с ноутбуком.

В выходном файле две колонки: `image_id,p_180`. Порядок строк берётся из `sample_submission.csv`.

## Модель и результат

Используется одна CNN **PP-LCNet x1.0** для определения ориентации текста. Последний классификационный слой дообучен на открытом наборе PaddleClas; тестовые изображения в обучении не участвовали. Предсказания для исходного и повёрнутого на 180° изображения усредняются.

**Подтверждённый балл на скрытом тесте:** `1 − Brier = 0.95582654` (Brier `0.04417346`). Ансамбль не используется.
